### 침수 안전 관리 시스템에서 맡은 일

- 시설·장치·센서 측정값 등을 관리하는 MySQL 테이블 12개를 설계하고, 로컬과 Azure 개발 환경에 적용해 주요 제약조건을 확인했습니다.

- 팀원이 개발 환경을 재현할 수 있도록 ERD, DB 적용 절차, API 요청 예시를 정리했습니다.
