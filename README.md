- 팀원이 개발 환경을 재현할 수 있도록 ERD, DB 적용 절차, API 요청 예시를 정리했습니다.

### 🔔 NotiFilter

중요한 알림을 놓치지 않도록, 사용자 기준에 따라 Android 알림을 분류하는 개인 프로젝트입니다. 초기 버전에서는 실기기에서 수신 알림 데이터를 확인하고 기본 필터링을 검증하는 것을 목표로 합니다. 사용자의 선호를 반영하는 AI 개인화는 이후 확장 기능으로 구상하고 있습니다.

### 부산의 밤, 빛으로 잇다 · 3D 드론쇼 시뮬레이션

비주얼컴퓨팅 수업의 3인 팀 프로젝트입니다. 파도와 갈매기로 시작해 부산항, 광안대교, 영화의전당으로 이어지는 공연을 기획했습니다. 드론 불빛을 재배열해 앞 장면의 형상이 다음 장면으로 이어지도록 연출합니다.

- **내 역할** · 전체 스토리라인과 6개 장면의 시간 배분·전환을 설계합니다. 일부 장면을 직접 구현하고, 팀원이 작업한 드론 대형·이동·시각 효과를 하나의 시뮬레이션으로 통합합니다.
- **구현 계획** · 공연 타임라인에서 드론 대형을 유지하는 시간과 이동 시작 시점을 설정하고, 장면 전환에 맞춰 조명의 색상과 밝기를 제어합니다.
